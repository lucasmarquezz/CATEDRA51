# CATEDRA51

Proyecto web para organizar apuntes, gráficos, algoritmos, encuestas y otros recursos académicos.

## Estructura

- `index.html` — página principal
- `pages/` — páginas internas
- `css/` — estilos
- `js/` — JavaScript

## Panel de administración

CATEDRA51 incluye un editor visual para el contenido, las tablas y el menú compartido. Antes de usarlo, configurá la autorización de GitHub y el Worker de Cloudflare siguiendo [ADMIN-SETUP.md](ADMIN-SETUP.md).
